# MJJ Navigation

快点 MJJ 导航网站，汇集 VPS、云服务器、域名、IDC 等相关资源链接。

## 功能

- 分类浏览各类 VPS/云服务器服务商
- 服务器监控工具集合
- 域名注册商导航
- 网络专线/IPLC 服务商
- 炼丹炉（GPU 算力平台）
- 汇率换算工具
- 全球数据中心地图

## 技术栈

- React 19
- Tailwind CSS 3
- React Simple Maps（数据中心地图）
- Heroicons

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm start

# 构建生产版本
npm build
```

## 数据配置

网站数据通过 `src/data/categories.json` 管理，可自行添加或修改分类和链接。
